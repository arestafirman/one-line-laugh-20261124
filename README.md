One funny line, one sentence, at most 200 characters — for the
[The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f)
bounty on make.fun.

`main.ts` writes the line deterministically to `/output/entry.txt`:

> The photocopy man charged me per page, then photocopied his own price list and charged me for that too.

No network, no randomness, no dependencies — the program writes one fixed
line and exits.
